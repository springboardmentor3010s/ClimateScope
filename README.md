🌍 ClimateScope – Global Climate Intelligence Dashboard

Overview
🚀 Live Demo
👉 Dashboard Link:
https://climatescope.onrender.com

ClimateScope is an interactive, end-to-end climate analytics platform that transforms raw global weather data into insights, predictions, and business intelligence.

It combines:

📊 Data Analysis
🌐 Interactive Visualizations
🔮 Predictive Analytics
💼 Economic Impact Modeling
☁️ Cloud Deployment

👉 Built as part of an internship project to demonstrate real-world data product development.

🎯 Key Features

📊 1. Executive Overview
Global KPIs (Temperature, Rainfall, Wind, Events)
Choropleth world map
Trend analysis
Top countries ranking

🌡 2. Temperature Intelligence
Monthly & yearly trends
Seasonal heatmaps
Distribution analysis
Multi-country comparison

🌧 3. Precipitation & Wind Intelligence
Rainfall trends
Wind speed patterns
Rain vs Wind relationship
Country-level ranking

🚨 4. Extreme Events Monitor
Heatwaves, heavy rain, high wind detection
Timeline & heatmap analysis
Risk-based insights

🌍 5. Regional Comparison
Side-by-side country comparison
Radar charts & bar analysis

⚠ 6. Climate Risk Intelligence
Composite Risk Score Model
Risk ranking by country
Trend & volatility analysis

🔮 7. Predictive Climate Analytics
Polynomial Regression forecasting
Future temperature prediction
Confidence interval (uncertainty cone)

💼 8. Economic Impact Model
Supply Chain Disruption estimation
Infrastructure Risk analysis
Agricultural Yield Volatility
Correlation heatmap

pip install -r requirements.txt
