# Climate change Analysis Dashboard

## Overview
This project analyzes income inequality across countries using data analytics and visualization.  
The dashboard focuses on comparing income distribution trends between **India, United States, and United Kingdom**.

Using Power BI and Python-based preprocessing, the project highlights how income distribution has evolved over time and how wealth is distributed between the top and bottom segments of the population.

## Objectives
- Analyze income trends over time
- Compare inequality using the **Gini Index**
- Examine income share of **Top 10% vs Bottom 10%**
- Visualize income distribution across countries
- Build an interactive **Power BI dashboard**

## Dataset
The dataset includes:

- Country
- Year
- Average Income
- Gini Index
- Top 10% Income Share
- Bottom 10% Income Share
- Income Group

## Data Preprocessing
Data cleaning and preprocessing were done using Python.

Tasks performed:
- Handling missing values
- Formatting income values
- Structuring dataset for Power BI
- Removing inconsistencies

## Dashboard Features

### Income Trend Over Time
Shows how average income changed from **2000–2023** across countries.

### Rich vs Poor Income Gap
Compares **Top 10% income share vs Bottom 10% share**.

### Inequality Comparison
Uses **Gini Index** to measure inequality levels.

### Income Group Distribution
Shows number of countries by income group:
- High Income
- Upper Middle Income
- Lower Middle Income
- Low Income

### Key Metrics
- Average Income
- Gini Index
- Top 10% Income Share
- Bottom 10% Income Share

## Technologies Used

- Power BI

## Key Insights

- The **Top 10% holds a significantly larger income share** compared to the Bottom 10%.
- Income inequality varies across countries, with noticeable differences in **Gini Index values**.
- Income trends show fluctuations influenced by economic growth and policy changes.
- Developed countries tend to have **higher average incomes but varying inequality levels**.
